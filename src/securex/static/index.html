02 / INTEGRITY

Trust, then verify.

Authenticate every encrypted file and compare its checksum with the encrypted catalog.

03 / RECOVERY

Keep a second copy.

Export an encrypted snapshot with its wrapped keys. Store it safely: a backup can recover files even after you remove them here.

Restore by extracting into an empty directory and launching SECUREX with that directory.

04 / ACCESS

A fresh passphrase.

Change how you unlock this vault without re-encrypting each file. Existing backups retain their old passphrase.

Know the boundaries.

SECUREX is an early release, not independently audited. It cannot protect an unlocked or compromised device, erase original files or backups, hide file sizes, or guarantee key erasure from SSDs, snapshots, swap, or memory.
