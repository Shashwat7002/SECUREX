# Security policy

SECUREX 0.1 is an early release and has not received an independent security audit. Its supported security boundary is documented in [the security model](docs/SECURITY_MODEL.md).

Please use this repository's **Security → Report a vulnerability** flow when available. If private reporting is not enabled, open an issue asking the maintainer for a private reporting channel without including exploit details or sensitive data. Do not post real vault contents, passphrases, launch tokens, or usable keys publicly.

Useful reports include the affected version, platform, minimal reproduction with synthetic files, expected behavior, and impact within the documented threat model. There is no paid bounty or guaranteed response SLA.

Security fixes target the current main branch. No long-term support policy is established yet.
